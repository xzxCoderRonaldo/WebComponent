# 高尿酸人群早晨空腹饮食指南

一个关于高尿酸人群早晨空腹饮食建议的健康指南网页应用。

## 功能特点

- 📋 详细的饮食建议和注意事项
- 🍎 推荐的低嘌呤食物列表
- 🍵 适合的茶类饮品推荐
- ⚠️ 重要的饮食禁忌和注意事项
- 💡 理想的早餐搭配建议
- 📱 响应式设计，支持移动端和桌面端

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器运行：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js (需要安装 http-server)
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000/uric-acid-diet/`

## 注意事项

⚠️ **重要提示**：本指南仅供参考，具体饮食方案请咨询专业医生或营养师。高尿酸血症和痛风的治疗需要结合个人具体情况，建议在医生指导下进行饮食调整。
